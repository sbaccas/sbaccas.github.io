Projects

  • Agent Zoo (Cat & Mouse): Autonomous Multi-Agent Spatial Reasoning & Deception Lab
    An authoritative 100×100 discrete 2D grid laboratory built with Google ADK, Gemini 2.5 Flash on Vertex AI, Model Context Protocol (MCP), and Agent-to-Agent (A2A) radio—testing whether frontier LLMs can invent spatial geometry (lawnmower sweeps, central trapdoor webs), dual-brain coaching strategies, and game-theoretic alliances or betrayals purely from Markdown skill manuals.
  • Wishart Ensemble Spectral Density and Combinatorial Maps
    A deep dive into random matrix theory and enumerative combinatorics, formalized in my Queen’s math thesis.
  • Bayesian Neural Networks: Uncertainty-Guided Recommendation in the Bandit Framework
    A framework combining Machine learning with exploration-exploitation trade-offs in online recommendation.
  • Misinformation Dynamics and Control
    Investigating control-theoretic interventions to reduce the spread and impact of misinformation in networks.
  • Quarantine Network Dynamics in DDoS Attacks
    A dynamical game-theory-based model for automated, cost-aware quarantining in response to distributed attacks.
  • AzSecuredLandingZone-Lab
    A lab project demonstrating secure Azure Landing Zone provisioning with identity segmentation, AVNM, and NSG hardening.
  • AzDDoS-SimulatorLab
    A high-intensity network simulation for modeling, testing, and tuning Azure DDoS Protection in a virtual lab environment.
  • Containerized Azure Function Python Workflow with Docker
    A lightweight template for rapidly building and testing Containerized Azure Python Function. Extremely useful serverless workhorses for CyberSecurity DevOps automation etc. Quick to deploy and cost efficient.
  • Software Support for High Quality Meshes of Museum Specimens
    Contributed to the design and development of tooling for generating and processing ultra-detailed 3D meshes of museum artifacts and biological specimens to support research, archiving, and public access.
