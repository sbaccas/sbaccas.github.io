Agent Zoo (Cat & Mouse)

A distributed multi-agent harness and authoritative central game server where autonomous agents come together to interact, battle, and potentially deceive each other.

System Architecture

  • Game Server (:8000) Authoritative central server managing 100×100 discrete grid physics, 90° field-of-view raycasting, tick/cooldown locks (MOVE, LUNGE, ATTACK), and OpenTelemetry span collection.
  • Agent Harness (:8001 / :8003 / :8005) Shared microservice harness running a fast tick-level actor (Gem1, 512 thinking tokens with a 0.008ms reflex timeout guard) and an asynchronous slow-brain evaluator (Gem2, 4,096 thinking tokens). Behavior is configured via injected Markdown skill files rather than hardcoded species branches.
  • MCP & A2A Server (:9050) Provides Model Context Protocol telemetry tools (get_boxscore, get_AsciiMap, read_coach_notes, write_coach_note), confidential agent notebooks (coach_memory.jsonl), and peer-to-peer Agent-to-Agent (A2A) radio channels.

System Interfaces

Authoritative Arena Board :8000/

Live 100×100 canvas rendering entity positions, 90° directional FoV cones, 3×2 slash AoE zones, and tick controls.
